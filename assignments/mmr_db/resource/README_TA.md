**🚀 Create Release Package (For TAs)**
To package and distribute the project skeleton (for grading or reuse), run:
```
make release
```
This will generate assignment3.tar.gz with:
- Skeleton source files in src/
- All test files in test/
- The Makefile, readme, README.md, and STUDENT_ID

**SRC Files Details**
Hash Table Implementations
- mmr_db_ht.c : skeleton
- mmr_db_ht_filled.c : simple answer
- mmr_db_ht_ext.c : answer with ht extension
Binary Search Tree Implementations
- mmr_db_bst.c : skeleton
- mmr_db_bst_filled.c : simple answer
- mmr_db_bst_id_only.c : working implementation only with ID bst
- mmr_db_bst_mmr_only.c : working implementation only with MMR bst
